# SaveSmith

**Редактор сохранений для одиночных игр. А если твоей игры нет в списке — её разберёт
твой ИИ-агент, и она появится в программе как своя.**

Открываешь программу — она сама находит установленные игры и показывает списком.
Выбираешь свою: SaveSmith найдёт сохранение, разберётся в его формате и покажет поля
с человеческими названиями — золото, уровень, характеристики, предметы с картинками.
Перед любой записью делает копию.

### [→ Скачать](https://daxil.github.io/SaveSmith/)

Страница сама определит, что у тебя за система, и даст нужный файл. Windows и macOS,
и Apple Silicon, и Intel.

---

## Игр — миллион. Как это может работать со всеми?

Никак, если разбирать их заранее по одной. Поэтому когда SaveSmith встречает игру,
которую никто не описал, он показывает кнопку **«Разобрать эту игру автоматически»**.

Дальше он спрашивает одно: какие числа ты видишь у себя в игре — золото, уровень,
здоровье. Заполняешь то, что помнишь, и жмёшь кнопку. Всё остальное программа делает
сама: находит установленного у тебя ИИ-помощника (Claude Code, Codex), сама пишет ему
задание, сама подбирает разбор файла и показывает, что происходит, строчка за строчкой.

**Тебе не нужно открывать консоль, ничего печатать и ничего настраивать.**

Числа нужны не для красоты: помощник ищет их в файле, и то место, где лежит твоё
золото, и есть поле «золото». Без них поля пришлось бы угадывать, а угаданное поле —
это когда счётчик голода подписан «здоровье» и ты его правишь.

Разбор считается удавшимся, только если файл собирается обратно **байт в байт**.
Разобрать и не суметь собрать — значит испортить сохранение, поэтому такой результат
не принимается. После удачи игра открывается в окне так же, как поддерживаемая: поля
по именам, предметы с картинками.

Помощник платит твоей подпиской — отдельного ключа и отдельной оплаты не нужно.

**Менять сохранения ему не разрешено — вообще.** Ему дано смотреть и предлагать;
записывает только человек. Подтвердить за тебя «понимаю, что за это банят» он тоже
не может.

**И честно:** для разбора куски твоего сохранения уходят туда, где этот помощник
работает. Программа спрашивает согласия до того, как что-то запустит, и без него не
начинает.

<details><summary>Если хочешь наоборот — водить SaveSmith своим агентом вручную</summary>

Он умеет и так: `savesmith mcp` отдаёт те же инструменты по Model Context Protocol.

```json
{
  "mcpServers": {
    "savesmith": { "command": "<путь к savesmith>", "args": ["mcp"] }
  }
}
```

</details>

**Нет никакого ИИ?** Тогда руками: скажи программе число, которое видишь на экране
игры, и она найдёт, где оно лежит в файле. Работает даже с зашифрованными сейвами —
проверено на настоящем Elden Ring.

```
savesmith search "C:\Games\Моя Игра" 12400
savesmith poke "C:\Games\Моя Игра" 0x1F4C:uint32-le 99999 --yes
```

Мест нашлось много? Сделай два сохранения — до и после того, как число изменилось:

```
savesmith diff сейв_до сейв_после --was 12400 --now 8000
```

Останется один-два адреса вместо сорока.

## Разобрался — отдай остальным

Работа по выяснению, где игра держит золото, стоит ровно столько, скольких людей она
достанет. Пока — одного тебя. Поэтому:

```
savesmith plugins --submit <id-плагина> --saves "<путь к игре>"
```

Команда сначала проверит плагин на твоих же сохранениях: каждое должно собираться
обратно байт в байт. Не сходится — не отправит.

**Сам сейв не уезжает никуда и никогда.** Уезжает только описание формата. В
сохранении лежит имя твоего персонажа, Steam ID и сколько ты наиграл — это другое, и
это никого не касается. Команда заодно проверит, не затесались ли в описание твоё имя
пользователя или путь к твоей папке, и откажется отправлять, если да: трекер
публичный, обратно не отзовёшь. Дальше открывается форма с заполненными полями — ты
читаешь всё, что уедет, и нажимаешь кнопку сам.

## Что обязательно надо знать

- SaveSmith — **для одиночных оффлайн-игр**. Не для онлайна.
- **Закрой игру перед правкой.** Многие игры держат сохранение в памяти и, выходя,
  перезаписывают файл своей версией — правка просто исчезнет.
- Правка сохранений часто нарушает пользовательское соглашение игры. Ответственность
  за последствия — на тебе.
- Встроенная оценка риска — **помощь, а не гарантия**. Незнакомая игра по умолчанию
  считается требующей осторожности, а не безопасной.
- Достижения могут сброситься. Steam Cloud может перезаписать правленый сейв старой
  версией, если не выполнить шаги, о которых программа предупредит.
- **На маке первый запуск скажет «SaveSmith is damaged and can't be opened».** Файл при
  этом целый: так macOS сообщает, что приложение не заверено у Apple, а заверение стоит
  $99 в год, которых у проекта пока нет. Кнопки «Всё равно открыть» в этом случае не
  появляется, поэтому нужна одна команда:

  ```
  xattr -dr com.apple.quarantine /Applications/SaveSmith.app
  ```

  Она снимает пометку «скачано из интернета», которую ставит браузер, — ничего в системе
  не отключает и касается только этого приложения. Кто не хочет трогать терминал, может
  собрать программу из исходников: тогда пометки не будет вовсе.
- **На Windows проще:** SmartScreen скажет «Windows защитила ваш компьютер» → «Подробнее»
  → «Выполнить в любом случае». Антивирус тоже может ругаться на сборки PyInstaller.

SaveSmith трогает **только файлы сохранений**. Он не читает и не пишет память чужих
процессов, не патчит `.exe` и `.dll`, ничего не внедряет в игру и не отключает защиту.
Это архитектурное решение: такого кода в проекте нет и не будет.

## Командная строка

Внутри это та же программа, что и окно. Нужна, если хочется того, чего в окне пока
нет: поиска числа, правки по адресу, сравнения двух сохранений. Ставить ничего не
надо — один файл, Python внутри.

```
savesmith games                             все игры, найденные на компьютере
savesmith find "<игра>"                     найти сейвы: папка, .exe или .app
savesmith show <сейв|папка>                 что в нём можно править
savesmith set <сейв|папка> <поле> <знач>    правка с бэкапом
savesmith items <сейв|папка>                инвентарь: что есть, выдать, убрать
savesmith backups <плагин>                  список копий и откат
savesmith search <сейв|папка> <число>       где лежит это число (без плагина)
savesmith poke <сейв|папка> <адрес> <знач>  правка по адресу (без плагина)
savesmith diff <до> <после> --was --now     найти поле, сравнив два сейва
savesmith prefs --game-folder <папка>       настройки Unity (PlayerPrefs)
savesmith mcp                               подключить свой ИИ к SaveSmith
savesmith plugins --submit <id> --saves <…> отдать свой плагин остальным
savesmith doctor                            что видно на этом компьютере
```

Путь к игре бери в кавычки, если в нём есть пробелы. На Windows файл можно просто
перетащить мышкой в окно `cmd` — путь подставится сам.

Пример от начала до конца:

```
savesmith games
savesmith show "C:\Games\Coin Quest"
savesmith set "C:\Games\Coin Quest" party._gold 99999
savesmith items "C:\Games\Coin Quest" --give "Эликсир" 5
```

Про предметы отдельно: названия и картинки берутся из файлов самой игры, поэтому не
устаревают с патчами. Если игра свои списки прячет — вещи покажутся её собственными
номерами, менять количество это не мешает. В окне то же самое выглядит как две сетки:
слева твоё, справа то, что бывает в игре; вещь перетаскивается мышкой.

Про Elden Ring: количество имеющихся вещей меняется, а выдать оружие или броню,
которых у персонажа нет, пока нельзя — у каждого экземпляра там своя заточка в
отдельной таблице. Программа скажет об этом словами, а не запишет мусор.

## Частые вопросы

**Нужен ли Python?** Нет. Один файл, внутри уже всё.

**Испортит ли это мой сейв?** Копия делается всегда, до записи, и возвращается одной
командой. Кроме того, программа отказывается писать, если после сборки файла не может
прочитать своё же изменение обратно.

**Работает на пиратке?** Да. Программа смотрит на файл сохранения, а не на то, откуда
взялась игра.

**Работает с Windows-играми на маке?** Да — Whisky, CrossOver, Wineskin. Бутылка
определяется сама, указывать ничего не нужно.

**А виртуальная машина (Parallels, VMware)?** Нет: файлы гостевой системы лежат внутри
образа диска, с хоста их не прочитать. Запусти SaveSmith внутри самой машины.

**Игра не видит мои изменения.** Она была запущена во время правки и перезаписала
файл. Закрой игру, откатись на копию, повтори.

**Какие форматы открываются без всякого ИИ?** gzip, zlib, base64, JSON, MessagePack,
LZString (RPG Maker MV и MZ), GVAS (Unreal Engine), BND4 и зашифрованные слоты
FromSoftware, Easy Save 3 (Unity), AES. Незнакомый файл разбирается перебором: если он
собран из знакомых слоёв, программа вскроет его сама.

| Платформа | Статус |

| macOS 13+ (Apple Silicon и Intel) | полностью |

## Где ещё взять файлы

**[Страница со «Скачать»](https://daxil.github.io/SaveSmith/)** — проще всего. Или
вручную, со [страницы последнего релиза](../../releases/latest):

| | Windows | macOS (Apple Silicon) | macOS (Intel) |
|---|---|---|---|
| **Окно** | `SaveSmith-…-windows-x64-setup.exe` | `SaveSmith-…-macos-arm64.dmg` | `SaveSmith-…-macos-x64.dmg` |
| **Командная строка** | `savesmith-…-windows-x64.exe` | `savesmith-…-macos-arm64` | `savesmith-…-macos-x64` |

Не знаешь, какой у тебя мак — меню  → «Об этом Mac». Apple M1/M2/M3/M4 значит arm64.
Рядом лежит `SHA256SUMS.txt`, если хочешь проверить, что файл скачался целиком.

**На маке файл командной строки после скачивания нужно один раз разрешить запускать** —
GitHub снимает с него это право, когда отдаёт:

```
chmod +x ~/Downloads/savesmith-*-macos-*
```

Окна это не касается: `.dmg` ставится обычным перетаскиванием.
Установленное окно дальше обновляется само — увидит новую версию и предложит.

Сборки со свежими изменениями, которые ещё не вышли релизом, лежат в артефактах
[GitHub Actions](../../actions) у каждого зелёного прогона.
