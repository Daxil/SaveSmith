# SaveSmith

Редактор сохранений оффлайн-игр, который умеет работать с играми, под которые редактора ещё не существует.

**Статус: ядро готово, окна пока нет.** Закрыты 7 вех из 8: поиск сохранений, разбор и
правка, классификатор риска, CLI, агент discovery, контрольные суммы, репозиторий плагинов.
Пользоваться можно из командной строки.

---

## Дисклеймер

Прочитай это до того, как что-то менять.

- SaveSmith предназначен **только для одиночных оффлайн-игр**.
- Правка сохранений часто нарушает пользовательское соглашение игры. Ответственность за
  последствия несёт пользователь.
- Встроенный классификатор риска — **помощь, а не гарантия**. Ban-политики разработчиков
  меняются, база рисков обновляется с задержкой, а неизвестная игра по умолчанию считается
  требующей осторожности, а не безопасной.
- Достижения могут быть сброшены, а Steam Cloud может перезаписать отредактированный сейв
  старой версией, если не выполнить шаги мастера облака.

SaveSmith трогает **только файлы сохранений**. Он никогда не читает и не пишет память чужих
процессов, не патчит `.exe`/`.dll` и не инжектит ничего в игру. Это архитектурное решение,
а не обещание: такого кода в проекте нет и не будет.

## Что уже работает

Весь бэкенд закрыт: вехи 1, 2, 3, 4, 6, 7 и 8. Осталось только окно — веха 5,
и её серверная половина (JSON-RPC) тоже готова.

```
uv run savesmith doctor                      что видно на этой машине
uv run savesmith scan                        установленные игры и их тир риска
uv run savesmith find "<папка игры>"         найти сейвы, зная только папку
uv run savesmith prefs --game-folder <папка> настройки Unity (PlayerPrefs)
uv run savesmith identify <файл>             определить формат
uv run savesmith checksum <файл>             найти контрольную сумму
uv run savesmith discover <файл>             полный разбор незнакомого формата
uv run savesmith discover <файл> --model     то же, но с моделью, если не вышло
uv run savesmith search <сейв|папка> <число>  где лежит это число
uv run savesmith poke <сейв|папка> <адрес> <знач>  правка без плагина
uv run savesmith show <сейв|папка игры>      что в нём можно править
uv run savesmith set <сейв|папка> <поле> <знач>  правка с бэкапом
uv run savesmith backups <плагин>            список и откат
uv run savesmith plugins                     плагины: список, установка, экспорт
uv run savesmith verify <плагин> <корпус>    round-trip гейт
```

**Поиск.** Резолвер путей с токенами под Windows и macOS; `{DOCUMENTS}` берётся
из `SHGetKnownFolderPath`, поэтому перенаправление OneDrive не ломает поиск.
Разбор библиотеки Steam. Бутылки Whisky, CrossOver, Wine и `.app`-обёртки
Wineskin. По папке игры определяется движок и выводятся места хранения сейвов.
`show` и `set` тоже принимают папку игры, а не только файл: если читаемый сейв
один — он и берётся, если несколько — печатается список и нужен `--slot`.
Угадывать слот программа не станет: не тот слот означает затёртый прогресс.

**Unity PlayerPrefs.** Многие игры на Unity держат прогресс не в файле, а в
реестре Windows или в plist на macOS. `find` показывает их рядом с сейвами,
`prefs --set` правит с бэкапом. Имена ключей восстанавливаются перечислением
того, что реально лежит в хранилище, а не переизобретением недокументированного
хеша Unity.

**Чтение и правка.** Формат описывается списком обратимых шагов: чтение гонит
его вперёд, запись назад. Операции: gzip, zlib, base64, xor, обрезка заголовка,
JSON, MessagePack, AES, Easy Save 3, LZString, GVAS (Unreal), BND4 и слоты
FromSoftware, контрольные суммы. Незнакомый файл разбирается перебором операций
в ширину, без модели.

**Игра без плагина.** Плагин — хороший исход, но пишет его человек, а игрок
с 12 400 рунами и без плагина ждать не должен. `search` принимает число,
которое видно на экране, и говорит, где оно лежит: путь (`player.gold`) для
структурных сейвов или смещение (`0x1F4C:uint32`) для двоичных. `poke` меняет
его по этому адресу, а обратная сборка сама пересчитывает контрольные суммы и
шифрует обратно. Проверено на настоящем сейве Elden Ring: BND4 распакован,
слот расшифрован, значение изменено, MD5 пересчитан, размер файла тот же.
Перед записью изменение вычитывается обратно из уже собранного файла — иначе
не узнать, что его не проглотил какой-нибудь шаг сборки. Какой из сорока
кандидатов имелся в виду, программа не угадывает: именно эта догадка и портит
сейвы. Если указана папка игры, перед записью печатается всё, что база рисков
знает про эту игру: правка без плагина обходит классификатор риска, но
замалчивать предупреждение, которое у нас есть, — хуже, чем не иметь его.

**Осторожность.** Классификатор риска сводит `risk_db.json`, анти-чит в папке
игры и тир из плагина. Неизвестная игра — `caution`, никогда не `safe`. Мастер
Steam Cloud блокирует запись, пока шаги не выполнены. Запись без бэкапа
невозможна по сигнатуре API. Плагин принимается, только если восстанавливает
файл байт в байт на всём корпусе.

**Discovery.** Явная машина из восьми шагов, где модель вызывается последней и
только для того, что не разобралось само. Сгенерированный код исполняется в
песочнице.

**Модель.** Шаг с моделью включается флагом `--model` и ограничен с трёх сторон:
бюджет в долларах (`--budget`, по умолчанию $1), число попыток (четыре) и гейт
round-trip — кодек принимается, только если `encode(decode(файл))` даёт файл
байт в байт. Ошибка каждой попытки уходит обратно в модель: исключение и
смещение первого расхождения. Сам файл не уходит никуда — модель пишет код, код
работает здесь. Для этого шага нужен `pip install anthropic` и свой
`ANTHROPIC_API_KEY`; без них всё остальное работает офлайн и бесплатно.

## Один файл, без установки

```sh
uv run pyinstaller savesmith.spec        # → dist/savesmith (13 МБ)
```

Плагины и база рисков лежат внутри бинаря. Человеку можно отдать один файл:
ни Python, ни uv, ни установки не нужно. CI собирает его на Windows, macOS
arm64 и macOS x86_64 при каждом пуше и кладёт в артефакты.

Подписи пока нет: macOS потребует снять карантин через Gatekeeper, а Windows
покажет «неизвестный издатель». Это лечится сертификатами, а не кодом.

## Разработка

Нужен [uv](https://docs.astral.sh/uv/). Python 3.12 uv поставит сам.

```sh
uv sync                # окружение и зависимости
uv run pytest          # тесты
uv run ruff check .    # линтер
uv run mypy            # типы
uv run mypy --platform win32   # типы так, как их видит Windows
```

Диагностика — что SaveSmith видит на твоей машине:

```sh
uv run python -m savesmith.core.diagnostics
```

## Поддерживаемые платформы

| Платформа | Статус |
|---|---|
| Windows 10/11 | первого класса |
| macOS 13+ (arm64 и x86_64) | первого класса |
| Windows-игры на маке (Whisky, CrossOver, Wine) | поддерживаются через сканер префиксов |
| Linux | не поддерживается, сообщение об ошибке вместо тихого сбоя |

**Виртуальные машины (Parallels, VMware, UTM) не поддерживаются.** Сейвы там лежат внутри
образа диска гостевой ОС, живой файловой системы, которую можно прочитать с хоста, у неё нет.
Запусти SaveSmith внутри самой виртуальной машины.
