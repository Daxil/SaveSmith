# SaveSmith

Редактор сохранений оффлайн-игр, который умеет работать с играми, под которые редактора ещё не существует.

**Статус: ранняя разработка.** Веха 1 из 8 — слой путей, парсер библиотеки Steam, сканер Wine-префиксов.
Редактировать сейвы пока нельзя, приложение только ищет их на диске.

---

## Дисклеймер

Прочитай это до того, как что-то менять.

- SaveSmith предназначен **только для одиночных оффлайн-игр**.
- Правка сохранений часто нарушает пользовательское соглашение игры. Ответственность за
  последствия несёт пользователь.
- Встроенный классификатор риска — **помощь, а не гарантия**. Ban-политики разработчиков
  меняются, база рисков обновляется с задержкой, а неизвестная игра по умолчанию считается
  требующей осторожности, а не безопасной.
- Достижения могут быть сброшены, а Steam Cloud может перезаписать отредактированный сейв
  старой версией, если не выполнить шаги мастера облака.

SaveSmith трогает **только файлы сохранений**. Он никогда не читает и не пишет память чужих
процессов, не патчит `.exe`/`.dll` и не инжектит ничего в игру. Это архитектурное решение,
а не обещание: такого кода в проекте нет и не будет.

## Что уже работает

Веха 1 закрыта — приложение умеет находить сохранения, но пока не читает их.

- Резолвер путей с токенами (`{LOCALLOW}`, `{DOCUMENTS}`, `{STEAM}` и прочие)
  под Windows и macOS. `{DOCUMENTS}` на Windows берётся из `SHGetKnownFolderPath`,
  поэтому перенаправление OneDrive не ломает поиск
- Разбор библиотеки Steam: все три поколения `libraryfolders.vdf`, список
  установленных игр с AppID, папки аккаунтов, признак Steam Cloud
- Сканер Wine-бутылок (Whisky, CrossOver, обычный Wine) с чтением `user.reg`
  и `dosdevices`, так что виндовые пути внутри бутылки резолвятся в реальные
  пути на маке
- Диагностика: `uv run python -m savesmith.core.diagnostics`

Дальше — веха 2, ядро плагинов. См. `PLAN.md`.

## Разработка

Нужен [uv](https://docs.astral.sh/uv/). Python 3.12 uv поставит сам.

```sh
uv sync                # окружение и зависимости
uv run pytest          # тесты
uv run ruff check .    # линтер
uv run mypy            # типы
```

Диагностика — что SaveSmith видит на твоей машине:

```sh
uv run python -m savesmith.core.diagnostics
```

## Поддерживаемые платформы

| Платформа | Статус |
|---|---|
| Windows 10/11 | первого класса |
| macOS 13+ (arm64 и x86_64) | первого класса |
| Windows-игры на маке (Whisky, CrossOver, Wine) | поддерживаются через сканер префиксов |
| Linux | не поддерживается, сообщение об ошибке вместо тихого сбоя |

**Виртуальные машины (Parallels, VMware, UTM) не поддерживаются.** Сейвы там лежат внутри
образа диска гостевой ОС, живой файловой системы, которую можно прочитать с хоста, у неё нет.
Запусти SaveSmith внутри самой виртуальной машины.
