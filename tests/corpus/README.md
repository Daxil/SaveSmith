# Тестовый корпус

Настоящие файлы сохранений, на которых прогоняется round-trip гейт. Синтетический
корпус проверяет реализацию; проверить, что мы правильно поняли, **что пишет игра**,
можно только на её собственных файлах.

## unreal-gvas/the-invincible

The Invincible (Starward Industries, Unreal Engine 4.27). Одиночная нарративная игра,
онлайна и анти-чита нет.

| Файл | Чем интересен |
|---|---|
| `GameSlotSave.sav` | Самый маленький, минимальный набор свойств |
| `ComicsSave.sav` | Массивы |
| `CondorSettings.sav` | Вложенные структуры |
| `MenuSettingsSave.sav` | Много свойств разных типов |
| `SaveSlot_0_backup_1.sav` | Полный игровой сейв, 350 КБ, крупные Map-свойства |

**Это личный игровой прогресс владельца репозитория.** Перед тем как делать репозиторий
публичным, файлы нужно либо убрать, либо заменить обезличенными.
