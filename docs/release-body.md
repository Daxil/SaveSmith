**Редактор сохранений для одиночных игр.** Указываешь папку, куда установлена игра —
программа сама находит сохранение, понимает формат и показывает, что можно поменять.
Перед любой записью делает копию.

## Что скачивать

| | Windows | macOS (Apple Silicon) | macOS (Intel) |
|---|---|---|---|
| **Окно** — просто нажать кнопку | `SaveSmith-{VERSION}-windows-x64-setup.exe` | `SaveSmith-{VERSION}-macos-arm64.dmg` | `SaveSmith-{VERSION}-macos-x64.dmg` |
| **Командная строка** — один файл, ничего не ставится | `savesmith-{VERSION}-windows-x64.exe` | `savesmith-{VERSION}-macos-arm64` | `savesmith-{VERSION}-macos-x64` |

Не знаешь, какой у тебя мак — меню  → «Об этом Mac». Если написано Apple M1/M2/M3/M4,
бери arm64.

`SHA256SUMS.txt` — контрольные суммы, если хочешь убедиться, что файл скачался целиком.

**Файл командной строки на маке нужно один раз разрешить запускать** — GitHub снимает с
него это право при выдаче:

```
chmod +x ~/Downloads/savesmith-{VERSION}-macos-*
```

Окна это не касается.

## Первый запуск: система будет ругаться

**Так и должно быть, и вот почему.** У программы нет цифровой подписи: сертификаты стоят
денег, которых у проекта пока нет. Ни macOS, ни Windows не могут отличить «подписи нет,
потому что автор не платит $99 в год» от «подписи нет, потому что это вирус», поэтому
пугают одинаково. Исходники открыты — собрать программу самому можно, и тогда верить на
слово не придётся.

**macOS.** Первый запуск даст «не удаётся проверить разработчика». Дальше:
Системные настройки → Конфиденциальность и безопасность → пролистать вниз →
**«Всё равно открыть»**. Спросят один раз.

**Windows.** SmartScreen скажет «Windows защитила ваш компьютер». Нажми
**«Подробнее»** → **«Выполнить в любом случае»**. Антивирус тоже может ругаться:
программы, собранные PyInstaller, регулярно попадают под эвристику.

## Прежде чем что-то менять

- Это **для одиночных оффлайн-игр**. Не для онлайна.
- Правка сохранений часто нарушает пользовательское соглашение игры. Ответственность
  за последствия — на тебе.
- **Закрой игру перед правкой.** Многие игры держат сохранение в памяти и, выходя,
  перезаписывают файл своей версией — правка просто исчезнет.
- Оценка риска внутри программы — помощь, а не гарантия. Незнакомая игра по умолчанию
  считается требующей осторожности.

SaveSmith трогает только файлы сохранений. Он не читает и не пишет память чужих
процессов, не патчит `.exe` и `.dll`, ничего не внедряет в игру и не отключает защиту.
