# Разработка

Внутреннее устройство и сборка. В README этого нет намеренно: он для того,
кто хочет починить свой сейв, а не читать про round-trip гейт.

## Как это устроено

Весь бэкенд закрыт: вехи 1, 2, 3, 4, 6, 7 и 8. Осталось окно — веха 5.

```
savesmith doctor                            что видно на этом компьютере
savesmith scan                              установленные игры и их тир риска
savesmith find "<папка игры>"               найти сейвы, зная только папку
savesmith show <сейв|папка>                 что в нём можно править
savesmith set <сейв|папка> <поле> <знач>    правка с бэкапом
savesmith search <сейв|папка> <число>       где лежит это число (без плагина)
savesmith poke <сейв|папка> <адрес> <знач>  правка по адресу (без плагина)
savesmith diff <до> <после> --was --now     найти поле, сравнив два сейва
savesmith prefs --game-folder <папка>       настройки Unity (PlayerPrefs)
savesmith backups <плагин>                  список копий и откат
savesmith identify <файл>                   определить формат
savesmith checksum <файл>                   найти контрольную сумму
savesmith discover <файл>                   разобрать незнакомый формат
savesmith plugins                           плагины: список, установка, экспорт
savesmith verify <плагин> <корпус>          round-trip гейт
```

**Поиск.** Резолвер путей с токенами под Windows и macOS; `{DOCUMENTS}` берётся из
`SHGetKnownFolderPath`, поэтому перенаправление OneDrive не ломает поиск. Разбор
библиотеки Steam. Бутылки Whisky, CrossOver, Wine и `.app`-обёртки Wineskin. Любая
команда, которой дают папку игры, сначала спрашивает, на какой машине эта папка
лежит: игра внутри бутылки хранит сейвы в её AppData, а не в Application Support
мака.

**Чтение и правка.** Формат описывается списком обратимых шагов: чтение гонит его
вперёд, запись назад. Операции: gzip, zlib, base64, xor, обрезка заголовка, JSON,
MessagePack, AES, Easy Save 3, LZString, GVAS (Unreal), BND4 и слоты FromSoftware,
контрольные суммы. Незнакомый файл разбирается перебором операций в ширину, без
модели.

**Unity PlayerPrefs.** Реестр на Windows, plist на macOS. Имена ключей
восстанавливаются перечислением того, что реально лежит в хранилище, а не
переизобретением недокументированного хеша Unity.

**Игра без плагина.** `search` принимает число с экрана и говорит, где оно лежит:
путь (`player.gold`) для структурных сейвов или смещение (`0x1F4C:uint32`) для
двоичных. `poke` меняет его по этому адресу, обратная сборка пересчитывает
контрольные суммы и шифрует обратно. Перед записью изменение вычитывается обратно из
уже собранного файла — иначе не узнать, что его не проглотил какой-нибудь шаг
сборки. Какой из сорока кандидатов имелся в виду, программа не угадывает: именно эта
догадка и портит сейвы.

**diff.** Оба сейва открываются со снятыми слоями. Сравнивать два зашифрованных
слота Elden Ring побайтово бессмысленно — изменилось всё. На двух настоящих сейвах
diff находит ровно два изменившихся байта и печатает адрес в том виде, который
принимает `poke`.

**Осторожность.** Классификатор риска сводит `risk_db.json`, анти-чит в папке игры и
тир из плагина. Неизвестная игра — `caution`, никогда не `safe`. Мастер Steam Cloud
блокирует запись, пока шаги не выполнены. Запись без бэкапа невозможна по сигнатуре
API. Плагин принимается, только если восстанавливает файл байт в байт на всём
корпусе.

**Discovery.** Явная машина из восьми шагов, где модель вызывается последней и
только для того, что не разобралось само. Сгенерированный код исполняется в
песочнице.

**Модель.** Шаг включается флагом `--model` и ограничен с трёх сторон: бюджет в
долларах (`--budget`, по умолчанию $1), число попыток (четыре) и гейт round-trip —
кодек принимается, только если `encode(decode(файл))` даёт файл байт в байт. Ошибка
каждой попытки уходит обратно в модель: исключение и смещение первого расхождения.
Сам файл не уходит никуда — модель пишет код, код работает здесь. Нужен
`pip install anthropic` и свой `ANTHROPIC_API_KEY`; без них всё остальное работает
офлайн и бесплатно.

## Собрать самому

Нужен [uv](https://docs.astral.sh/uv/). Python он поставит сам.

```sh
uv sync                        # окружение и зависимости
uv run pytest                  # тесты
uv run ruff check .            # линтер
uv run mypy                    # типы
uv run mypy --platform win32   # типы так, как их видит Windows

uv run pyinstaller savesmith.spec   # → dist/savesmith (10 МБ)
```

Плагины и база рисков лежат внутри бинаря: человеку можно отдать один файл. CI
собирает его на Windows, macOS arm64 и macOS x86_64 при каждом пуше.

Диагностика — что SaveSmith видит на твоей машине:

```sh
uv run python -m savesmith.core.diagnostics
```

Запись в `docs/demo.gif` сделана скриптом, который сам запускает собранный бинарь и
рисует его настоящий вывод, — чтобы она не могла разойтись с тем, что программа
делает на самом деле.

## Окно (веха 5)

Фронтенд в `gui/`: React 19 + TypeScript + Vite. Оболочки Tauri ещё нет — для
неё нужен Rust, которого на машине разработчика может не быть.

```sh
cd gui
npm install
npm run dev      # http://localhost:5173
npm test         # тесты транспорта
npm run build    # tsc --noEmit + сборка
```

`npm run dev` сам поднимает бэкенд: плагин в `vite.config.ts` запускает
`dist/savesmith rpc` дочерним процессом и гоняет `POST /rpc` в его stdin. То
есть интерфейс проверяется против настоящего ядра, а не против макета, который
с ним согласен. Бинарь должен быть собран заранее.

**Почему stdio, а не локальный HTTP-порт в самой программе.** Порт без
аутентификации доступен любой странице, открытой у пользователя в браузере, а
этот процесс умеет перезаписывать файлы сохранений. Труба доступна только тому,
кто её создал. В разработке порт слушает Vite, живёт ровно пока идёт разработка
и в поставку не входит.

Правила окно не хранит: оно показывает `may_write`, `blockers`, тир риска и шаги
Steam Cloud так, как их сформулировало ядро. Экран, который смог бы обойти любое
из этих правил, — ошибка в `gui/src/rpc.ts`, а не возможность интерфейса.

Осталось: оболочка Tauri (`gui/src-tauri/`), которая запускает тот же бинарь
сайдкаром, диалог выбора папки вместо поля ввода, подпись и нотаризация.
